# Icon Assets

Place the following SVG icons in this directory:

## Skill Icons
- `wordpress.svg` - WordPress logo
- `shopify.svg` - Shopify logo
- `elementor.svg` - Elementor logo
- `woocommerce.svg` - WooCommerce logo
- `uiux.svg` - UI/UX design icon
- `cloudflare.svg` - Cloudflare logo

## Where to Get Icons
You can download official brand logos from:
- WordPress: https://wordpress.org/about/logos/
- Shopify: https://www.shopify.com/brand-assets
- Elementor: https://elementor.com/press/
- WooCommerce: https://woocommerce.com/brand-assets/
- Cloudflare: https://www.cloudflare.com/press/

For UI/UX icon, you can use a generic design icon from:
- Heroicons: https://heroicons.com/
- Feather Icons: https://feathericons.com/

## Notes
- All icons should be SVG format for scalability
- Recommended size: 64x64px viewBox
- Use monochrome versions where possible (they will be styled with CSS)
